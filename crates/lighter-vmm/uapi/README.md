# Linux UAPI headers for the V4L2 bindings

`v4l2r`, which `virtio-media` builds on, generates its bindings from `linux/videodev2.h` at build time, and a Mac has no such header. These are the ones it needs, copied unchanged from Linux 6.18.52 (`include/uapi/`), plus three stand-ins: `asm/ioctl.h` and `asm/types.h`, which arm64 takes from `asm-generic`, and `sys/time.h`, the C library header the UAPI header includes for `struct timeval`. `.cargo/config.toml` points `V4L2R_VIDEODEV2_H_PATH` here; the copy of `videodev2.h` at this level is what that variable looks for, and the `linux/` tree is what the header's own includes resolve against. The bindings are generated for `x86_64-linux-gnu`, the only 64-bit target the crate offers, whose layouts match arm64's for everything V4L2 defines.
